# 이미지 가이드 및 이미지 메이커 에이전트 명세 리포트

본 리포트는 guides/image_guide.md 및 agents/image_maker.md 문서 생성을 위해 이미지 규격, 생성 방식, 에이전트 역할을 정의합니다.

***

## 1. 이미지 가이드(guides/image_guide.md) 핵심 규정

* 대표 이미지 규격
  * 크기: 1080px 곱하기 1080px (1대1 정사각형)
  * 배경 색상: 어두운 블루 퍼플 그라데이션 (#1a1a2e 에서 #16213e)
  * 텍스트: 글 제목(큰 글씨 흰색), 카테고리 및 부제(작은 글씨 연한 회색), 가로 세로 중앙 정렬
  * 폰트: Pretendard 또는 시스템 기본 한글 폰트
  * 액센트: 우측 하단 또는 좌상단에 작은 도형, 코드 심볼, 단순 아이콘 표기

* 본문 삽입 이미지 4종류
  1. 비교 표: 제품 및 방법을 나란히 비교할 때
  2. 단계별 다이어그램: 절차나 순서를 보여줄 때
  3. 핵심 포인트 카드: 3개에서 5개 요점을 정리할 때
  4. 인용 및 강조 박스: 중요한 한 마디를 강조할 때

* 공통 렌더링 규칙
  * HTML 과 CSS로 레이아웃을 작성하고 Python의 Playwright 라이브러리를 실행하여 PNG 이미지로 캡처
  * AI 및 테크 분위기에 어울리는 어두운 톤 배경 사용
  * 코드 블록 스타일 및 모노스페이스 폰트 조화

***

## 2. 이미지 메이커 에이전트(agents/image_maker.md) 역할

* draft.md 파일 내의 [IMAGE: 설명] 태그 및 제목 정보를 탐색합니다.
* guides/image_guide.md 규격에 적합한 HTML CSS 코드를 생성합니다.
* Python Playwright 캡처 스크립트를 작성 및 실행하여 PNG 이미지 파일들을 output/[주제]/images/ 경로에 저장합니다.
* draft.md 내의 [IMAGE: 설명] 표시를 캡처된 실제 마크다운 이미지 링크로 교체합니다.
* 전체 산출물 및 문서 내에서 ASCII 하이픈 문자를 일체 사용하지 않습니다.
