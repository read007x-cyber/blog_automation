# 네이버 브라우저 복원 팝업 제거 및 클린 상태 발행 구축 리포트

본 리포트는 브라우저 진입 시 노출되는 복원 팝업 및 이전 글 불러오기 모달을 자동 차단하고, 이미지 첨부 시 OS 파일 탐색기 창 유발을 방지하여 발행 직전 브라우저 위에 방해 요소가 전혀 없는 클린 상태(Clean State)에서 마우스 호버 초록색 발행 버튼 클릭을 진행하고 실서버 포스팅을 완성한 내역을 기록합니다.

***

## 1. 정밀 구축 사양

* 브라우저 시작 플래그 및 복원 팝업 자동 닫기:
  1. 복원 창 차단 기동 옵션 적용
  2. 에디터 진입 후 Escape 키 전송 및 취소 새로쓰기 닫기 버튼을 클릭하여 복원 모달 완전 제거
* 파일 탐색기 창 유발 차단 및 클린 상태 확보:
  1. 상단 사진 버튼 타격 대신 DOM 레벨 input[type="file"]에 setInputFiles 직접 주입
  2. 발행 직전 3회 연속 Escape 키 전송으로 화면 상 띄워져 있는 레이어 요소 모두 제거
* 마우스 호버 2차 초록색 발행 버튼 클릭 완결:
  1. 1차 발행 클릭 후 우측 팝업 오픈 확인
  2. 2차 발행 버튼 좌표로 page.mouse.move() 호버 전송하여 초록색 변경 1.5초 대기
  3. 초록색으로 활성화되었을 때 page.mouse.click() 으로 실서버 완료 제출 전송
  4. 완료 후 사용자의 블로그 메인 포스팅 목록 페이지로 리다이렉트 이동 및 화면 영구 유지
* 검수 스크린샷: output/아쿠아슈즈 인기와 가성비 비교 분석/naver_upload_result.png
