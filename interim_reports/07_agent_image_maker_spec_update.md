# 이미지 메이커 에이전트 상세 명세 업데이트 리포트

본 리포트는 agents/image_maker.md 지침 문서에 자율 검수 루프, 사용자 이미지 처리 기능, 파일 치환 절차를 상세히 반영하기 위한 명세를 기록합니다.

***

## 1. 주요 추가 및 변경 기능

* 대표 이미지 및 본문 이미지 생성
  * 대표 이미지: output/[주제]/images/thumbnail.png (1080px 1대1 비율)
  * 본문 이미지: 등장 순서대로 body_1.png, body_2.png 형태로 output/[주제]/images/ 디렉토리에 저장

* 이미지 자체 검수 루프 (Self Inspection Loop)
  * 캡처된 PNG 이미지를 시각적 확인 도구(view 도구)를 통해 점검
  * 확인 항목: 하단 빈 여백 과다 여부, 텍스트 자름 및 상자 이탈 여부, 레이아웃 비뚤어짐 여부
  * 결함 발견 시 HTML 및 CSS를 보정하고 최대 3회까지 다시 캡처 및 검수 진행

* 사용자 제공 이미지(user_images 디렉토리) 옵션 활용
  * user_images 폴더 내 사용자 이미지가 존재하는 경우 view 도구로 분석
  * 본문 맥락에 부합하는 위치의 [IMAGE: ...] 마커를 해당 사용자 이미지로 대체
  * 분석된 이미지 특징을 바탕으로 SEO 최적화 대체 텍스트(alt 텍스트) 및 캡션 자동 생성

* draft.md 파일 내 마커 최종 치환
  * [IMAGE: 설명] 태그를 생성된 마크다운 이미지 링크로 직접 치환 업데이트

***
