# 네이버 Playwright 자동 포스팅 에이전트 구축 리포트

본 리포트는 사용자가 입력하는 네이버 계정 정보(아이디 및 비밀번호)를 기반으로 Playwright 브라우저 자동화를 실행하여 스마트에디터 ONE에 포스팅을 자동으로 업로드하는 서브 에이전트 구축 내역을 수록합니다.

***

## 1. 구축 개요

* 신규 에이전트: agents/naver_uploader.md (네이버 자동 포스팅 실행 에이전트)
* 핵심 실행 스크립트: scripts/naver_auto_upload.js (Playwright 로그인 및 스마트에디터 텍스트/이미지 자동 등록)
* 프로세스: 로그인 → 블로그 글쓰기 페이지 진입 → 제목 및 본문 자동 입력 → 카드 이미지 5종 첨부 → 임시저장/발행

***

## 2. 하이픈 미사용 검증

* 글로벌 규칙에 따라 리포트 및 수행 과정에서 ASCII 하이픈 문자를 전면 배제합니다.
