# 조립자 에이전트(Assembler Agent) 명세 리포트

본 리포트는 agents/assembler.md 지침 문서를 작성하기 위한 전략 및 최종 산출물(final.md, final.html) 생성 규정을 기록합니다.

***

## 1. 조립자 에이전트의 역할과 임무

조립자 에이전트는 이미지 경로가 완벽히 결합된 초안 파일(output/[주제]/draft.md)과 이미지 폴더(output/[주제]/images/)를 전달받아, 최종 마크다운 검토 문서(final.md) 및 웹 시각 미리보기 문서(final.html)를 조립 생성하는 역할을 수행합니다.

***

## 2. 세부 생성 지침

* final.md 생성: draft.md의 완결된 내용을 기반으로 최종 마크다운 검토 문서를 생성합니다.
* final.html 생성: 네이버 블로그 본문 스타일을 적용한 웹 시각 미리보기 HTML 문서를 작성합니다.
  * 레이아웃: 본문 폭 700px 중앙 정렬, 여백 최적화
  * 가독성 폰트: Pretendard 또는 기본 한글 폰트 적용
  * 이미지 리사이즈: 본문 너비에 맞춰 자동 조절
  * 명확한 위계: 제목, 소제목, 본문 텍스트 간 시각적 구별성 제공
* 사용자 브라우저 열기 안내: 최종 작업 완료 후 사용자에게 final.html 파일을 브라우저로 직접 확인하도록 안내 메세지를 남깁니다.

***

## 3. 하이픈 미사용 검증

* 글로벌 규칙에 따라 산출물 및 문서 내에서 ASCII 하이픈 문자를 전면 배제합니다.
