## 2. 수집된 핵심 기능 5가지 분류

* 첫 번째: 터미널 환경과의 완전한 통합 및 다이렉트 파일 편집 (Terminal Native Integration & Direct File Operations)
* 두 번째: 프로젝트 전체 맥락 파악 및 깊이 있는 코드 검색 (Codebase Awareness & Deep Code Search)
* 세 번째: 자율적 에이전틱 워크플로우 및 서브에이전트 활용 (Agentic Workflow & Subagents Task Delegation)
* 네 번째: MCP (Model Context Protocol) 기반 외부 시스템 확장성 (MCP Open Standard Integration)
* 다섯 번째: CLAUDE.md 기반의 지속적 메모리 및 팀 가이드라인 적용 (Persistent Memory & Project Conventions)

## 3. 비교 분석 및 한계점 (정보 충돌 및 이견 사항)

* 경쟁 도구(Cursor, Aider) 대비 특성: IDE 통합 중심의 Cursor나 Git 커밋 중심의 Aider와 달리, 클로드 코드는 쉘 명령 실행 및 자율 에이전트 작업에 특화되어 있음.
* 한계 및 고려사항: Anthropic 모델 전용 제한, 권한 승인 절차에 따른 흐름 간섭, 대규모 세션 시 API 토큰 소비량 관리 필요성.
