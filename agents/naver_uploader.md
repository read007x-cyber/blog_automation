# 네이버 블로그 다이렉트 자동 업로더 서브 에이전트 (agents/naver_uploader.md)

이 에이전트는 사용자가 저장해 둔 Persistent Context 세션을 바탕으로 Node Playwright 브라우저를 구동하여, 네이버 블로그 글쓰기 페이지 접근 시 "작성 중인 글이 있습니다" 팝업이 뜨면 '확인' 버튼을 클릭하여 수용하고, 기존에 남아있던 제목 및 본문 텍스트와 이미지를 깨끗이 전체 삭제(Clear All)한 후 실제 사람이 타자를 치듯 한 글자씩 타이핑(Human Typing)하며 마크다운 이미지 마커 위치에 맞춰 해당 카드 이미지를 1대1로 정밀하게 삽입하여 임시저장하는 역할을 담당합니다.

***

## 1. 입력 자료 및 설정
* NAVER_ID (사용자 네이버 아이디)
* output/[주제]/ (final.md 및 images/ 디렉토리)
* scripts/naver_auto_upload.js (팝업 확인 및 전체 삭제 후 휴먼 타이핑 및 위치별 이미지 자동 첨부 엔진)
* scratch/naver_user_data (보존된 로그인 세션 디렉토리)

***

## 2. 작동 방식 및 실행 절차
1. output/[주제]/final.md 파일 및 images/ 디렉토리 파싱
2. 스마트에디터 ONE 진입 후 "작성 중인 글이 있습니다" 팝업 감지 시 '확인' 버튼 클릭
3. 제목 란 및 본문 영역 포커스 후 전체 선택(Ctrl+A / Cmd+A) 및 Backspace를 수행하여 기존에 작성되어 있던 내용 완전 삭제 (Clear All)
4. 제목 란에 새 제목을 한 글자씩 타이핑(delay 60ms)
5. 본문 텍스트 단락을 한 글자씩 타이핑(delay 35ms)하며, 마크다운 이미지 마커 위치에 도달하면 해당 이미지 파일(thumbnail, body_1 ~ body_4)을 그 자리에 정확히 첨부
6. 포스팅 작성 완결 후 '저장' 버튼을 클릭하여 임시저장 수행 및 output/[주제]/naver_upload_result.png 스크린샷 보관

***

## 3. 핵심 안전 및 사용자 경험 규칙
* 작성 중인 글 팝업이 발생하는 경우 확인 버튼을 수용하여 작성 에디터를 확보
* 작성 시작 전 기존 텍스트 및 이미지를 깔끔하게 지운 후 새로운 포스팅 작성을 진행
