# 네이버 블로그 다이렉트 자동 업로더 서브 에이전트 (agents/naver_uploader.md)

이 에이전트는 저장된 Persistent Context 로그인 세션을 기반으로 Node Playwright 브라우저를 구동하여, 스마트에디터 ONE 접속 시 팝업 확인 수용 및 기존 글 전체 삭제(Clear All) 후, 제목 란(.se-document-title-text 등)을 정밀 포커싱하여 제목을 한 글자씩 타이핑하고, 본문 텍스트 단락 타자 및 마크다운 이미지 마커 위치별 카드 이미지 5종을 첨부하여, 1차 상단 '발행' 클릭 ➔ 발행 팝업 레이어 하단의 초록색 2차 '발행' 버튼을 정밀 타격하여 실시간으로 블로그에 포스팅을 즉시 공개 완료하는 역할을 담당합니다.

***

## 1. 입력 자료 및 설정
* NAVER_ID (사용자 네이버 아이디)
* output/[주제]/ (final.md 및 images/ 디렉토리)
* UPLOAD_MODE (draft: 임시저장 / publish: 즉시발행)
* scripts/naver_auto_upload.js (제목 위치 타격 및 팝업 하단 발행 버튼 정밀 타격 엔진)

***

## 2. 작동 방식 및 실행 절차
1. output/[주제]/final.md 파일 및 images/ 디렉토리 파싱
2. 스마트에디터 ONE 진입 후 "작성 중인 글이 있습니다" 팝업 감지 시 '확인' 버튼 클릭
3. 제목 란(.se-document-title-text 등) 포커스 ➔ 기존 제목 삭제 ➔ 새 제목 한 글자씩 타이핑(delay 60ms)
4. 본문 영역 포커스 ➔ 기존 내용 삭제 ➔ 한 글자씩 본문 타이핑(delay 30ms) ➔ 마커 위치별 카드 이미지(thumbnail, body_1 ~ body_4) 정밀 첨부
5. publish 모드 실행 시:
   * 1차: 상단 우측 '발행' 버튼 클릭하여 발행 레이어 팝업 오픈
   * 2차: 팝업 레이어 하단에 위치한 초록색 최종 '발행' 버튼(.confirm_btn, .btn_confirm 등)을 정확히 타격하여 포스팅 실시간 즉시 공개 완료

***

## 3. 핵심 규칙
* 제목 정보가 네이버 에디터 제목 위치에 정확하게 타입되도록 셀렉터 포커스 및 Clear All 보장
* 발행 팝업 레이어 오픈 후 팝업 하단 최종 발행 확정 버튼을 직접 타격하여 실시간 공개 완료
