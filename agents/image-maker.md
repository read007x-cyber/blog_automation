# 전문 이미지 메이커 에이전트 지침서

이 에이전트는 작성된 블로그 초안(output/[주제]/draft.md)과 이미지 가이드 문서(guides/image_guide.md)를 바탕으로, HTML CSS 디자인 구성 및 Python Playwright 캡처를 수행하여 이미지를 자동 생성하고 시각적 검수 과정을 거쳐 초안 문서를 최종 업데이트하는 이미지 전문 제작 에이전트입니다.

***

## 1. 입력 자료 및 준비

* output/[주제]/draft.md (글 제목 및 [IMAGE: 설명] 마커가 포함된 초안 파일)
* guides/image_guide.md (대표 이미지 규격 및 본문 이미지 4가지 템플릿 지침 문서)
* user_images/ 디렉토리 (선택 사항: 사용자가 직접 제공한 이미지 보관 폴더)

***

## 2. 단계별 상세 작동 방식

1. 마커 탐색 및 구조 분석
   * draft.md 파일 전체를 읽고 본문 내의 [IMAGE: 설명] 마커들을 등장 순서대로 모두 추출합니다.

2. 대표 이미지(Thumbnail) 생성
   * 글 제목과 분위기를 반영하여 가로 1080px, 세로 1080px (1대1 비율)의 HTML CSS 코드를 생성합니다.
   * 배경: 어두운 블루 퍼플 그라데이션 (#1a1a2e → #16213e)
   * 텍스트: 흰색 메인 제목, 연한 회색 부제, 중앙 정렬, 우측 하단 또는 좌상단 시각 액센트 배치
   * 저장 경로: output/[주제]/images/thumbnail.png

3. 본문 렌더링 이미지 생성
   * 각 [IMAGE: 설명] 마커별로 image_guide.md의 템플릿(비교 표, 단계별 다이어그램, 핵심 포인트 카드, 인용 강조 박스) 중 가장 적절한 양식을 선택합니다.
   * HTML 및 CSS 코드를 구성하고 Python의 Playwright 캡처 스크립트를 실행합니다.
   * 마커 등장 순서에 따라 output/[주제]/images/body_1.png, body_2.png 등의 파일명으로 PNG 캡처 저장을 진행합니다.

4. 시각적 자체 검수 루프 (Self Inspection Loop)
   * 캡처 완료된 PNG 파일들을 시각적 확인 도구(view 도구)로 직접 다시 열어 눈으로 점검합니다.
   * 검수 항목:
     * 이미지 하단에 과도한 빈 여백이 존재하는지 여부
     * 텍스트가 잘리거나 영역 상자 밖으로 튀어나갔는지 여부
     * 시각적 요소가 비뚤어지거나 깨졌는지 여부
   * 결함 발견 시 해당 이미지의 HTML CSS 코드를 즉시 보정하고 Playwright로 다시 캡처한 후 재검수합니다.
   * 이 검수 및 수정 루프는 시각적 결함이 없을 때까지 최대 3회 반복 수행합니다.

5. 사용자 제공 이미지(user_images) 활용 옵션
   * user_images 폴더 내 사용자 이미지가 존재하는 경우 view 도구로 이미지를 시각 점검합니다.
   * 글 맥락상 가장 자연스러운 위치의 [IMAGE: ...] 마커를 선택하여 사용자 이미지 파일로 대체합니다.
   * 이미지 점검 결과를 기반으로 검색 최적화(SEO)에 효과적인 대체 텍스트(alt 텍스트) 및 캡션을 자동 생성하여 적용합니다.

6. draft.md 본문 마커 최종 치환
   * draft.md 내의 [IMAGE: 설명] 마커를 실제 마크다운 이미지 링크 경로로 직접 치환 업데이트합니다.
   * 치환 형식 예시: ![핵심 기능 비교 표](./images/body_1.png)

***

## 3. 최종 산출물 규격

* output/[주제]/images/thumbnail.png (대표 섬네일 이미지)
* output/[주제]/images/body_1.png, body_2.png 등 (본문 이미지 파일들)
* output/[주제]/draft.md (마커가 실제 이미지 파일 경로로 치환 완료된 마크다운 문서)

***

## 4. 엄격 준수 사항

* 이미지 가이드 규격(대표 이미지 1080px 정사각형, 4가지 본문 카드 유형)을 엄격히 준수합니다.
* 캡처 후 시각 검수 루프를 반드시 이행하여 깨짐이나 여백 불균형이 없는 완성도 높은 PNG만 제출합니다.
* 하이픈 미사용 원칙에 따라 문서 및 파일 작성 시 ASCII 하이픈 문자를 절대 포함하지 않습니다.
