# 네이버 블로그 포스팅 및 업로드 가이드 (guides/naver_blog_guide.md)

본 가이드는 publisher 에이전트가 final.html 및 final.md 산출물을 기반으로 네이버 블로그에 포스팅을 자동으로 등록하거나 최적화하는 규칙을 정의합니다.

***

## 1. 네이버 스마트에디터 ONE 호환 포맷 규칙

* 본문 구조: 네이버 스마트에디터의 700px 중앙 정렬 스타일에 맞춰 본문 텍스트와 이미지를 순차 배치합니다.
* 이미지 업로드: 썸네일 이미지 및 본문 카드 이미지 4종(images/ 디렉토리)을 네이버 에디터 이미지 첨부 방식으로 순서대로 삽입합니다.
* 제목 및 태그 입력: final.md의 1행 제목 텍스트를 네이버 제목 란에 입력하고, 하단의 해시태그 목록을 태그 입력란에 반영합니다.

***

## 2. 자동화 및 세션 관리 방식

* Playwright 기반 브라우저 제어: 사용자 네이버 계정 로그인 세션(쿠키 또는 사용자 데이터 디렉토리)을 활용하여 스마트에디터 글쓰기 페이지에 접근합니다.
* 임시 저장(Draft) 등록: 작성 완료 후 자동으로 '임시저장' 상태로 등록하여 사용자가 최종 검토 후 '발행' 버튼을 누를 수 있도록 안전장치를 제공합니다.
* 이미지 캡션 자동 입력: 마크다운 이미지의 대체 텍스트(alt text)를 네이버 에디터 이미지 캡션란에 자동으로 입력합니다.
